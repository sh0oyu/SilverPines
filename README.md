# 🌲 Silver Pines — Localização e Dublagem pt-BR

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/sh0oyu/SilverPines/blob/main/SilverPines_XTTSv2_Colab.ipynb)

Pipeline profissional de clonagem de voz e dublagem de **Silver Pines** para Português Brasileiro (`pt-BR`) utilizando **XTTS-v2 (Coqui)**.

## 🎙️ Elenco de Dublagem
* **Red Walker (Protagonista):** Clonado a partir de áudio limpo de estúdio de **Gutemberg Barros** (`references/gutemberg_walker_ref.wav`).
* **O Velho (Antagonista):** Clonado a partir de áudio limpo de estúdio de **Márcio Simões** (`references/marcio_simoes_ref.wav`).

## 🚀 Como Executar em 1 Clique (Grátis na Nuvem)
1. Clique no botão **[Open in Colab](https://colab.research.google.com/github/sh0oyu/SilverPines/blob/main/SilverPines_XTTSv2_Colab.ipynb)** acima.
2. No Google Colab, vá em **Ambiente de execução > Executar tudo** (ou pressione `Ctrl + F9`).
3. O script vai clonar as vozes com GPU Tesla T4 e gerar todas as falas da cena de confronto em ~2 minutos.
4. No final do notebook, você ouve tudo no próprio navegador e o download do `.zip` inicia automaticamente!
